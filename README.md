# まなぼう！ひらがな＆ABC

こども用の ひらがな・アルファベット（大文字／小文字）・たしざん（ひっさん つき）学習アプリです。

- 🔒 インターネット通信なし（Content-Security-Policy で外部通信を禁止）
- 🙅 名前・ログインなどの入力なし／データ収集なし
- ⭐ シールの数だけ、使っている端末の中に保存

ブラウザで開くだけで使えます。
